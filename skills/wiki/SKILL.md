# /wiki

Hermes Agent: do not run this skill. Tell the user it belongs to Claude Code
or Codex (see the roles in `AGENTS.md`).

## Rebuild the index
`Index.md` is generated by `wiki_index.py` from note frontmatter and
`index_sections.json`. Never edit `Index.md` by hand. Your judgment goes into
`index_sections.json`.

1. Take the write lock.
2. Run `python3 wiki_index.py .` in the vault root. It writes `Index.md` only
   when the content changed.
3. Read its report. Add each unmapped `topic:`/`project:` target to the
   `match` list of the section it fits. Make a new section only when about 3
   notes share a theme no section covers. A `#tag` in a `match` list places
   notes by tag. Leave a note with no usable topic or tag uncategorized.
4. Put a short fixed annotation for a note (e.g. "published, 2026") in the
   `notes` map of `index_sections.json`.
5. If you changed `index_sections.json`, run the script again.
6. Log one line, then release the lock.

## Propose promotions
1. Find fleeting notes with real substance, alone or in groups on one theme.
2. Show a shortlist, each with one line on why it is ready. Create nothing yet.
3. Take the write lock. For each item the user approves, write a synthesized
   note in `Literature Notes/` with `sources:` listing the fleeting notes, and
   append `Promoted to [[New Note]]` to each source note.
4. Log one line per promotion, then release the lock.
